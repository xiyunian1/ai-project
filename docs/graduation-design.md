# WMS 智能仓储辅助决策系统毕业设计说明

## 课题名称

基于 Spring Boot 与 Vue 的 WMS 智能仓储辅助决策系统设计与实现

## 系统定位

本系统面向仓储运营场景，围绕库存风险识别、自然语言数据分析、资料增强问答和文档处理构建统一工作台。系统目标不是替代完整 WMS，而是在已有仓储数据基础上提供更高效的查询、分析和辅助决策能力。

## 功能模块

- 用户认证与权限：登录、JWT 鉴权、修改密码；公开注册关闭，普通账号由管理员创建。
- 智能对话：围绕仓储资料、制度说明和业务问题进行资料增强问答与文本交流。
- 分析助手：支持自然语言库存分析、SQL 明细回看、连续追问和业务结论生成。
- 库存洞察：展示低库存预警、风险分级、优先处理清单，并支持跳转生成分析建议。
- 资料管理：上传、查看和删除当前账号的业务资料知识文档，供智能对话优先引用。
- 文档处理：上传文档、填写处理要求、预览和下载处理结果。
- 系统配置：集中维护真实 SQL 数据库连接和模型配置，分析助手直接使用这里保存的配置。
- 用户管理：管理员创建普通账号、调整角色、启用/禁用、重置密码和删除账号。
- 账号设置：查看当前账号、修改密码、切换主题和退出登录。

## 技术架构

- 前端：Vue 3、Vite、Vue Router、Electron 可选打包。
- 后端：Spring Boot、Spring MVC/WebFlux、Spring Data JPA、JWT。
- 数据库：SQL Server 业务库，测试环境使用 H2。
- AI 集成：OpenAI 兼容模型接口、DeepSeek/NL2SQL，演示时使用真实模型调用。

## 核心业务流程

1. 用户使用管理员账号登录系统，前端保存 JWT 并进入智能工作台。
2. 用户可先进入资料管理，上传制度、流程、商品说明等业务资料，形成当前账号的知识文档。
3. 用户进入库存洞察，查看低库存商品、风险分级和优先处理清单。
4. 用户选择某条高风险商品，点击“生成处理建议”。
5. 系统跳转到分析助手，并自动带入针对该商品的风险分析问题。
6. 用户发送问题，后端通过 SQL 分析服务访问真实数据库，返回分析结论和 SQL 明细。
7. 用户可切换到智能对话，基于已上传资料继续做制度解释、异常说明和业务问答。

## 演示流程

1. 打开登录页，说明系统面向 WMS 仓储运营场景。
2. 使用默认管理员账号登录，介绍智能对话、分析助手、库存洞察、资料管理和文档处理等核心模块。
3. 进入资料管理页，展示知识资料上传、分类和引用关系。
4. 点击低库存商品的“生成处理建议”。
5. 在分析助手中发送预置问题，查看分析结果和 SQL 明细。
6. 切换到智能对话，演示系统如何优先引用已上传资料进行问答与说明整理。
7. 可选展示文档处理或用户管理，作为系统扩展与后台管理能力。

如需调整 SQL 数据库连接或模型 API Key，进入左侧“系统配置”功能区统一维护；分析助手将直接使用这里保存的真实数据库连接和模型配置。

真实 SQL Server 演示的启动、登录和接口检查步骤见 `docs/sqlserver-demo-runbook.md`。

## 演示稳定性说明

- 本地开发和毕业演示默认使用真实模型调用；若外部 AI 服务不可用，应显示错误并检查模型配置。
- SQL 分析包含只读限制、表白名单和 SQL 修复保护，降低危险 SQL 风险。
- 文档处理依赖 Codex CLI，可作为扩展模块展示；若本机未配置 Codex CLI，可重点演示上传界面和接口设计。
