# 设计文档：AI 创意门户大厅集成网站 (Home.vue)

本项目旨在为 `ai-frontend` 新增一个具有现代科技感、高视觉冲击力、且带有微交互的 **AI 创意公开门户大厅**。该主页可供所有未登录与已登录的用户访问，作为平台对外展示与引流的核心窗口，同时为“AI视频生成”、“AI图片生成”、“AI PPT生成”和“AI音乐生成”四大核心功能板块预留开发空槽与模拟微交互，免去后期重构框架的成本。

---

## 1. 总体设计架构

### 1.1 路由与导航调整
- **原路由机制**：`/` 重定向到 `/login`。
- **新路由机制**：
  - `/` 指向全新设计的公开主页 `Home.vue`。
  - `/login` 和 `/register` 保持原有功能，从大厅右上角可以便捷跳转。
  - 主页引入全局导航栏，支持检测用户当前的登录状态（读取 `USER_TOKEN` 和用户名）。
    - *若未登录*：右上角显示“登录”、“注册”按钮。
    - *若已登录*：右上角显示“进入工作台 (WMS智能助手)”、“退出登录”以及用户头像/昵称。

### 1.2 页面布局与视觉
主页将完全延续并放大项目现有的玻璃拟态和微光动效风格（参考 `theme.css` 中的 `--page-gradient`、`--page-glow` 和网格背景）：
1. **Header (全局导航)**：高斯模糊玻璃拟态，固定在顶部，带有平滑的边缘光和暗色切换适配。
2. **Hero Segment (主标展示区)**：
   - 居中呈现诗意与科技感并重的标语：“AI 创意引擎中心 / 释放指尖的无限可能”。
   - 动态微光的微尘粒子动画（使用 CSS 纯样式或轻量 SVG 动画实现），确保顺畅不卡顿。
3. **Core Grid (四大创意板块)**：
   - 两行两列或一行四列的响应式网格布局。
   - 每一张卡片对应一个 AI 创意板块：**AI视频生成**、**AI生成图片**、**AI生成PPT**、**AI生成音乐**。
   - 卡片本身采用毛玻璃背景（`backdrop-filter`），带有悬浮边缘流光（Hover edge border animation）与优雅的升降阴影。

## 2. 核心板块与模拟微交互设计

为了让网站在各板块功能“未实质接入后端”前依然生动、专业，且便于后续开发者“无缝填空”，我们为四个板块量身定制了**微交互占位机制**：

### 2.1 AI 视频生成 (AI Video Generator)
- **UI 预留**：一个大文本提示词输入框（Placeholder: "例如：一个赛博朋克风格的雨夜街道，霓虹灯闪烁..."）、生成比例选择器（16:9 / 9:16）、“立即生成”高亮按钮、右侧/下方的视频预览黑槽。
- **微交互逻辑**：
  1. 用户可以随意输入或点击“随机灵感”。
  2. 点击“立即生成”后，按钮变为 Loading 状态，视频预览区呈现带百分比的骨架屏（“正在渲染关键帧...” -> “正在进行音视频合成...”）。
  3. 耗时 3 秒左右后，展示一段精美的内置 AI 动画（优雅的循环空镜视频或由 CSS 渲染的梦幻场景），并弹窗/下方提示：“当前为演示模式。完整自定义视频生成服务正在接入中，可查看代码中的 `<slot name="video-api">` 绑定后端”。

### 2.2 AI 生成图片 (AI Image Generator)
- **UI 预留**：多风格选择器（写实、动漫、3D、国风）、尺寸比例（1:1, 4:3, 16:9）、负向提示词输入框、生成按钮。
- **微交互逻辑**：
  1. 点击“立即生成”，图片槽位触发极高质感的光斑扫过动画（Shimmer skeleton gradient）。
  2. 模拟加载完成，渲染一张与所选风格呼应的、具有艺术美感的默认插画。
  3. 提供“下载高清原图”、“相似生成”等置灰按钮，并写有明确的 `mockImageApi` 函数，提示后期只需替换该函数中的 base64 返回值即可。

### 2.3 AI 生成 PPT (AI PPT Designer)
- **UI 预留**：PPT 主题输入框（如“2026年终业务总结”）、受众选择、一键生成大纲按钮。
- **微交互逻辑**：
  1. 点击生成后，下方平滑展开手风琴组件（Accordion），模拟 AI 实时生成大纲的过程：
     - *第一阶段*：标题拟定。
     - *第二阶段*：三到四个核心章节（如“市场分析”、“财务数据”、“未来展望”）逐字打字机吐出。
     - *第三阶段*：章节内要点（Bullet Points）渐显。
  2. 提供一个模拟的“PPT幻灯片双向卡片预览槽”，展示精致的排版。
  3. 标注清晰的组件 Slot，方便接入后期的 PPT 导出（如 pptx.js）或后端 HTML 转 PPT 服务。

### 2.4 AI 生成音乐 (AI Music Studio)
- **UI 预留**：音乐曲风选择（Lofi、史诗、电子、爵士）、情绪词（欢快、宁静、紧张）、时长滑块，下方附带一个极具未来感的迷你玻璃播放器。
- **微交互逻辑**：
  1. 输入曲风点击生成后，迷你播放器中央出现呼吸式环形声波波纹（CSS scale/opacity 循环动画）。
  2. 3 秒模拟计算后，播放器加载一首优美舒缓的内置免版权 Lofi 背景音乐（可循环播放、暂停、调节音量、拖动进度条）。
  3. 音乐播放时，声波波纹伴随节奏抖动（使用纯 CSS 动画模拟，无需复杂 Web Audio API 绑定，降低出错率）。

## 3. 技术栈与工程规范
- **框架支持**：Vue 3 Composition API (`<script setup>`)，不添加额外的外部重度依赖，全部使用项目已引入的 `Element Plus`、`vue-router` 和标准原生的 CSS / SVG 资产。
- **样式方案**：完全接入并复用 `src/styles/theme.css`。响应式基于 CSS Flexbox 与 Grid，并完美兼容移动端及 Electron 客户端。
- **易维护性**：
  - 微交互的 Mock 逻辑全部提取到专门的 `src/utils/homeMock.js` 文件中，并配有极其详细的汉语代码注释。
  - 核心展示组件抽离至 `src/views/Home.vue`（或通过分子文件夹拆分），并在代码中预留明显的 `<!-- TODO: BACKEND_INTEGRATION_SLOT -->`，方便后续开发人员接手。

---

## 4. 自检清单 (Spec Self-Review)
1. **占位符检查**：不含有任何未定的 TBD/TODO 内容，所有模拟数据与内置媒体资产全部设计妥当。
2. **路由连贯性**：进入主页不需要 `USER_TOKEN` 验证，点击“登录”或“进入工作台”时，自动衔接现有的权限守卫机制（`beforeEach`）。
3. **代码零污染**：主页是一套独立的视觉组件，不修改和影响现有的仓储 WMS 助手或聊天功能页面，保证系统原有逻辑 100% 稳定运行。
